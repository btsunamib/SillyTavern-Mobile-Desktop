# 手机桌面布局 · Mobile Desktop 1.0.0

给 SillyTavern 手机端提供桌面式三栏：左侧 AI 参数、中间聊天、右侧角色管理。左右两栏可以独立调宽、收起，聊天区随之变化。

## 安装（压缩包方式）

1. 解压本压缩包，得到 `SillyTavern-Mobile-Desktop` 文件夹。
2. 将整个文件夹放进运行 SillyTavern 的服务器/电脑上的下列任一目录：
   - 当前用户：`SillyTavern/data/<你的用户目录>/extensions/SillyTavern-Mobile-Desktop/`
   - 所有用户：`SillyTavern/public/scripts/extensions/third-party/SillyTavern-Mobile-Desktop/`
3. 确认 `manifest.json` 直接在该文件夹内，避免套了两层同名文件夹。
4. 刷新酒馆页面，在“扩展 → 管理扩展”中确认扩展已启用。
5. 点击右下角 **布局**，打开 **启用桌面布局**。

这是酒馆 UI 扩展，不是 Chrome/Safari 扩展，也不是服务器插件。它安装在运行酒馆的机器上，随后手机用浏览器打开同一个酒馆即可使用。手机无需安装 APK。

如果你只能访问别人提供的酒馆地址、不能管理服务器文件，需要由其管理员安装。

## 从 Git 仓库安装

在酒馆中打开 **扩展 → 安装扩展**，粘贴下面的地址并安装：

```text
https://github.com/btsunamib/SillyTavern-Mobile-Desktop
```

安装后刷新页面，点击右下角 **布局**，打开 **启用桌面布局**。默认先保持酒馆原生布局，手动启用后才生效。安装到运行完整 SillyTavern 的电脑或服务器即可，手机浏览器打开同一个酒馆就能使用。

这是扩展仓库地址，不是独立网页，也无需启用 GitHub Pages。

## 使用

- **桌面画布**（默认 1200 px）：改变移动浏览器的布局视口宽度，让酒馆使用其桌面断点。初始缩放会让整幅桌面适应屏幕；可以双指缩放，放大后移动视图。画布宽度范围为 1024–2400 px。推荐横屏。
- **屏幕内三栏**：保持手机视口和手机字号，在当前屏幕内排成三栏。竖屏空间有限，左右栏可能很窄，可收起暂时不用的侧栏。
- **左右宽度**：分别通过滑块、数字框设定 80–600 px。这里是布局像素，不是手机物理像素。
- **拖动调整**：拖动两条淡蓝色分隔线。键盘聚焦分隔线后也可按方向键，按住 Shift 时每步调整更多。
- **显示/隐藏**：设置中的复选框、右下角“左 / 右”按钮、顶部原生左右栏图标都可切换。聊天区自动填满空余空间。
- **自动适配**：侧栏合计过宽时按比例缩小，以尽可能保留聊天区的最小宽度。面板显示“实际宽度”，你的目标宽度保留不变。
- **快捷预设**：均衡三栏、聊天优先、手机三栏。
- **设置入口**：右下角“布局”，或“扩展设置 → 手机桌面布局 → 打开布局设置”。
- **保存**：使用酒馆账户的扩展设置自动保存。首次安装默认关闭，避免未经操作就改变界面。启用状态也会保存，之后刷新自动恢复。
- **恢复**：点击“恢复原生布局”即可还原原视口及原来的左右抽屉开关、锁定状态。参数会保留；“重置参数”则恢复默认值并关闭布局。完全禁用扩展后建议刷新一次，兼容旧版酒馆的加载方式。

布局按钮和设置面板会抵消页面缩放，在手机上仍保持可触摸大小。

## 兼容范围与限制

- 按 SillyTavern 官方 UI 扩展接口编写；核对的本地官方源码版本为 `1.19.0`，提交 `06bde93`。
- 需要官方完整酒馆的扩展加载器、`SillyTavern.getContext()`、扩展设置 API，以及 `#left-nav-panel`、`#right-nav-panel`、`#sheld` 结构。源码相同的分支一般可用；没有扩展加载器的纯静态仿制版不能直接安装。
- 桌面画布改变 CSS 断点，不会伪装浏览器 User-Agent，也不改变酒馆判断移动设备的所有 JavaScript 行为。这是界面布局扩展。
- 宽画布整体缩小时文字会小；通过横屏、减少画布宽度、双指放大或切换“屏幕内三栏”改善。
- 浏览器或 PWA 对 viewport、缩放及软键盘的处理可能不同；尚未进行真机 iOS/Android 验证。
- 窄侧栏中的酒馆原生复杂表格可能需要横向滚动。与其他大幅改造布局的扩展、移动 UI 拖拽及强制定位的自定义 CSS 同时使用时可能发生冲突。
- 设置保存到酒馆账户，使用同一账户的其他设备也会读到同一配置；本扩展也可用于电脑。
- 不请求聊天数据，不发送外部网络请求，不改核心文件，不覆盖核心主题、移动 UI 坐标或锁定设置。

## 文件

- `manifest.json`：扩展清单与生命周期钩子。
- `index.js`：设置、视口、拖动、保存与状态还原。
- `layout.js`：参数校验与布局宽度计算。
- `style.css`：通过独立类名启用的三栏样式。
- `LICENSE`：MIT 开源许可证。

参考：[官方 UI 扩展文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[官方源码](https://github.com/SillyTavern/SillyTavern)。
